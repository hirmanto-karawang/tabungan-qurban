📞 TROUBLESHOOTING TIPS
================================================================================

Jika ada error:
1. Buka browser console (F12)
2. Check error message
3. Baca FILES_SUMMARY.md untuk file description
4. Lihat troubleshooting section di INSTALLATION_GUIDE.md

Common Issues:
- "Cannot read properties" → Check config.js URL update
- "Service Worker registration failed" → Clear cache
- "Login failed" → Check test user di Google Sheet
- "WhatsApp not sending" → Check Fonnte API key
